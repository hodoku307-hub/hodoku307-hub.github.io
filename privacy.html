だれが使うか

zundamon-uploader は、持ち主が自分の YouTube チャンネルのためだけに使う個人用のツールです。ほかの人には提供していません。

使う情報

Google アカウントの許可（OAuth）を使って、YouTube Data API で次のことだけをします。

  • 持ち主のチャンネルの動画の一覧と、その動画の設定を読む
  • 動画を非公開で上げ、タイトル・概要欄・タグ・サムネイル・公開の予約を入れる

情報の置き場所と共有

  • 許可の情報（トークン）は、持ち主のパソコンの中だけに置きます。
  • YouTube から読んだ情報を、ほかの人や会社に送ったり、売ったり、広告に使ったりはしません。
  • YouTube の情報は、上に書いたことのためだけに使います。

許可の取り消し

許可は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）から、いつでも取り消せます。

YouTube と Google のポリシー

このツールは YouTube API サービスを使っています。YouTube の利用規約と Google のプライバシー ポリシーもご覧ください。

Privacy Policy (English summary)

zundamon-uploader is a personal tool used only by its owner for their own YouTube channel. Through Google OAuth and the YouTube Data API, it only lists the owner's videos and their settings, uploads videos as private, and sets titles, descriptions, tags, thumbnails and scheduled publication. Tokens are stored only on the owner's computer. No YouTube data is shared, sold or used for advertising. Access can be revoked at any time at https://myaccount.google.com/connections. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Contact: hodoku307-hub on GitHub.
