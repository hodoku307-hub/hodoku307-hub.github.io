channel-manager プライバシーポリシー

制定日：2026年11月28日

1. このツールについて

channel-manager（以下「本ツール」）は、運営者が自分の YouTube チャンネルの運用を振り返るために使う個人用のツールです。運営者以外の方の利用は想定していません。

2. 取得する情報

運営者本人が Google アカウントで許可したときだけ、YouTube Data API と YouTube Analytics API を通じて、次の情報を読み取り専用で取得します。

  • 運営者のチャンネルの情報（チャンネル ID・チャンネル名）
  • 運営者のチャンネルの動画の情報（タイトル・公開日時など）
  • 運営者のチャンネルの統計（再生回数・視聴時間・クリック率など）

視聴者個人を特定する情報は取得しません。

3. 使い方

取得した情報は、運営者のチャンネルの振り返り（どの動画が伸びたかなどの集計）にだけ使います。広告、販売、ほかの目的には使いません。

4. 保存と共有

  • 取得した情報と、許可のための鍵（トークン）は、運営者のパソコンの中にだけ保存します。
  • 第三者に提供・販売・共有しません。
  • 運営者が自分で見るための通知（Discord）に、集計した数字の要約を送ることがあります。

5. Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含む Google API Services User Data Policy に従います。

6. 許可の取り消しと削除

許可は、Google アカウントの「サードパーティのアプリとサービス」（https://myaccount.google.com/connections）からいつでも取り消せます。取り消した後は、運営者のパソコンの中の保存した情報を削除できます。

7. YouTube と Google のポリシー

本ツールは YouTube API サービスを使っています。YouTube の利用規約と Google のプライバシー ポリシーもご覧ください。
